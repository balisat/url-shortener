# URL Shortener with Analytics

A single-file HTML/CSS/JavaScript web app that shortens a long URL and tracks analytics for the links you create.

## What it does

- Shortens a long URL into a short code.
- Tracks total links created.
- Shows recent activity for links and visits.
- Displays clicks per link.

## How to run it

- Open `index.html` in a web browser, or
- Serve this repository with GitHub Pages, where `index.html` is the entry page.

No build step or installation is required.
